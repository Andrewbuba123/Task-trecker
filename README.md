# Task Tracker

## Описание

Task Tracker — небольшое frontend-приложение для создания и отслеживания задач.
Пользователи регистрируются, создают задачи, берут чужие в работу и завершают их.
Данные хранятся в браузере (Local Storage), для проверки уже есть демо-данные.

Демо: [task-trecker-two.vercel.app](https://task-trecker-two.vercel.app/)

## Возможности

- регистрация и вход, сессия сохраняется после перезагрузки страницы;
- создание задач с валидацией полей (название, описание, количество работников);
- главная страница со списком актуальных задач;
- взять чужую задачу в работу и завершить её;
- удалять задачу может только её автор;
- страница «Мои задачи» с разделением на задачи в разработке и выполненные, счётчик активных задач в меню;
- задачи сохраняются в Local Storage и остаются после перезагрузки.

## Установка и запуск

Склонировать репозиторий:

```bash
git clone https://github.com/Andrewbuba123/Task-trecker.git
```

Перейти в папку проекта:

```bash
cd Task-trecker
```

Установить зависимости:

```bash
npm install
```

Запустить сервер разработки:

```bash
npm run dev
```

При первом запуске в приложении уже есть демо-данные: два пользователя и восемь задач в разных статусах. Для проверки войдите под любым из них:

| Логин   | Пароль    |
| ------- | --------- |
| `demo1` | `demo123` |
| `demo2` | `demo123` |

Можно и зарегистрировать свой аккаунт. Чтобы вернуть демо-данные, очистите Local Storage сайта (DevTools → Application → Local Storage → Clear) и обновите страницу.

## Сборка

Чтобы собрать production-версию, выполните:

```bash
npm run build
```

Готовые файлы появятся в папке `dist/`.

## Скрипты

- `npm run dev` — сервер разработки
- `npm run build` — проверка типов и сборка в `dist`
- `npm run preview` — просмотр собранной версии
- `npm run lint` — ESLint
- `npm run typecheck` — проверка типов TypeScript
- `npm run format` / `npm run format:check` — форматирование Prettier
